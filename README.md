# 🎬 Subasree D - Portfolio Website

A modern, Netflix-themed personal portfolio showcasing my journey as a MERN Stack Developer. Built with React, Vite, and GSAP animations.

[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/subasreebhoopesh/portfolio-website)

## 🚀 Features

- **Netflix-Inspired UI/UX** - Cinematic black and red theme with smooth animations
- **Responsive Design** - Optimized for desktop, tablet, and mobile devices
- **Interactive Components** - Custom cursor, spotlight effects, and scroll animations
- **Project Showcase** - 6 real GitHub projects with live links
- **Certifications Section** - Professional certificates and achievements
- **Tech Stack Display** - Comprehensive list of technologies and skills
- **Downloadable Resume** - Direct PDF download functionality
- **GSAP Animations** - Smooth scroll-triggered and entrance animations

## 🛠️ Tech Stack

### Frontend

- **React Hooks** - State and lifecycle management

## 🚦 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/subasreebhoopesh/portfolio-website.git
   cd portfolio-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```

## 📦 Deployment

### Deploy to Vercel (Recommended)

1. Push code to GitHub
2. Visit [vercel.com](https://vercel.com)
3. Import your repository
4. Deploy with one click

### Deploy to Netlify

1. Run `npm run build`
2. Drag and drop the `dist` folder to [netlify.com](https://netlify.com)

## 🎨 Customization

### Update Personal Information
Edit the following files:
- `src/components/Hero.jsx` - Name, title, bio
- `src/components/About.jsx` - About section content
- `src/components/Projects.jsx` - Project data
- `src/components/Contact.jsx` - Contact information

### Update Colors
Modify Tailwind classes in components:
- Primary: `red-600`
- Background: `#050505`, `#141414`
- Text: `white`, `white/80`

### Add/Remove Sections
Edit `src/App.jsx` to add or remove components
